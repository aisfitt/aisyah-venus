📂 ViewBinding

ViewBinding merupakan fitur untuk mempermudah inisialisasi komponen di Activity tanpa perlu menggunakan findViewById(). melainkan berdasarkan atribut id , sehingga akan terhindar dari NullPointerException.

Penerapan ViewBinding

1️⃣ Aktifkan ViewBinding di build.gradle (Module: app) dan lakukan Sync Project

Pada file tersebut, cari buildFeatures dan tambahkan viewBinding=true didalamnya

...
    buildFeatures{
        viewBinding = true
    }
...

2️⃣ Ubah inisialisasi btnKirim dan inputNoTujuan menggunakan viewBinding.

Buatlah variable global binding di ThirdActivity :

class ThirdActivity : AppCompatActivity() {

		private lateinit var binding: ActivityThirdBinding
		
		override fun onCreate(savedInstanceState: Bundle?) {
			...
		}
}

ActivityThirdBinding ini menyesuaikan nama layout yaitu activity_third.xml.
Jika nama layout activity_home.xml maka tipe data untuk variaabel binding ialah ActivityHomedBinding

📂 Attribute Components

  • wrap_content → Ukuran elemen menyesuaikan dengan isi di dalamnya
  • match_parent → Ukuran elemen akan memenuhi ruang yang tersedia dari parent
  • layout_marginHorizontal →Memberikan margin Left dan Right dari parent
  • layout_marginVertical → Memberikan margin Top dan Bottom dari parent
  • backgroundTint → Memberikan warna background Button

    Klik pada kota warna disamping untuk menampilkan color picker

Beberapa attribute umum lainnya:

AtributFungsi
paddingHorizontalMemberikan jarak horizontal antara isi elemen dengan batas elemen itu sendiri
paddingVerticalMemberikan jarak vertikal antara isi elemen dengan batas elemen itu sendiri
textSizeMengatur ukuran teks dalam satuan sp
backgroundMenentukan warna atau gambar sebagai latar belakang elemen
backgroundTintMenyesuaikan warna overlay pada latar belakang elemen
gravityMenentukan posisi teks di dalam elemen

visibilitySet elemen terlihat (visible), tidak terlihat (invisible), atau tidak ada (gone)

3️⃣ Menggunakan String dari strings.xml

Penggunaan strings.xml dilakukan agar text dapat terdefinisikan sama di seluruh tempat, sehingga jika ada perubahan, cukup menyesuaikan yang ada di file tersebut tanpa harus merubah di tempat lainnya.

Silahkan buka /xml/strings.xml lalu didalam tag <resources> tambahkan seperti berikut:

Jika kita mendefinisikan string verif , maka string tersebut dapat digunakan dengan cara @string/verif

<TextView
		android:id="@+id/textVerif"
		android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:textSize="25sp"
    android:text="@string/verif"
    android:fontFamily="@font/monsterrat_black"/>

Atribut text pada TextView akan mengambil value dari string.xml dengan name verif

Penggunaan colors.xml dilakukan agar warna dapat terdefinisikan sama di seluruh tempat.

📂 Intent (Berpindah antar Activity)

Apa itu Intent?

Intent adalah komponen penting dalam Android untuk menghubungkan satu halaman (Activity) ke halaman lainnya. Misalnya, jika klik tombol "Next", maka kamu berpindah ke halaman selanjutnya.

Agar lebih terlihat dalam penggunaan Intent, kita akan coba siapkan halaman baru saat tombol “Kirim” ditekan.

1️⃣ Buat Activity baru dengan nama ThirdResultActivity di pertemuan_3

Silahkan desain activity_third_result.xml sesuai keinginan yang penting isinya menampilkan info “Kode berhasil dikirim! Silahkan periksa nomor Anda”

2️⃣ Pada ThirdActivity, Ubah toast menjadi Intent yang memanggil ThirdResultAcitvity pada saat klik btnKirim
binding.btnKirim.setOnClickListener {
		...
		
    val intent = Intent(this, ThirdResultActivity::class.java)
    startActivity(intent)
}
3️⃣ Jalankan aplikasi dan tes apakah berhasil berpindah ke halaman saat klik tombol Kirim
